# Manrope

Variable font with Latin and Cyrillic glyphs, weights 200–800. Hosted locally
through `next/font/local` so rendering and builds do not depend on a font CDN.

Source: [Google Fonts](https://github.com/google/fonts/tree/main/ofl/manrope).
`Manrope[wght].ttf` is stored here as `Manrope-Variable.ttf` without changes.
The SIL Open Font License is included in `OFL.txt`.
